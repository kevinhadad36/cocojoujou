# CocoJoujou
Site de jeux colorés pour enfants musulmans. Page unique index.html (HTML/CSS/JS, zéro dépendance sauf Google Fonts).
- Design : grille "catalogue" façon Superr (Refero), palette très colorée, enfants en SVG (6 teintes de peau, visages sans yeux), ballons, pois.
- 6 jeux : memory, pop (ballons 1..n), quiz, color, letters (alphabet arabe), wudu. Étoiles en localStorage.
- Règles : pas d'instruments/musique, pas de visages réalistes, pas de pub, pas de collecte de données. Ne pas nommer Claude Code/Lovable.
- Idée : ajouter de nouveaux jeux dans GAMES + une fonction dans le moteur.
